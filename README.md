# Threat Correlation & Forecasting Assistant

## Problem Statement
SOC teams receive thousands of security alerts daily. Reviewing every alert manually is time-consuming and may cause important threats to be missed.

## Solution
This project correlates security alerts, removes duplicate alerts, handles missing timestamps, maps alerts to MITRE ATT&CK techniques, calculates threat scores, and provides a forecast.

## Features
- CSV alert upload
- Duplicate alert removal
- Missing timestamp handling
- Same-source alert correlation
- MITRE ATT&CK mapping
- Threat scoring
- Threat forecasting
- Interactive dashboard
- Final security report

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- CSV
- MITRE ATT&CK concepts

## Project Files
- `index.html` – Interactive dashboard
- `alerts.csv` – Sample alert dataset
- `correlate_alerts.py` – Alert correlation and analysis code
- `final_report.txt` – Final security report

## How to Run
Open `index.html` in a browser or visit the GitHub Pages website.
