Attack Chains — Overview
Detailed Threat Reports

Methodology: Proof-of-concept. Rule-based temporal correlation (10-minute sliding window per source IP), MITRE ATT&CK technique mapping (approximate), explainable risk-prioritization scoring (NOT CVSS), and knowledge-based forecasting using documented ATT&CK post-exploitation relationships. No custom ML model is used at any stage of the pipeline.

Score ceiling: MAX_SCORE = 28 (T1595=2 + T1110=5 + T1098=7 + T1048=8 + T1498=6). Each technique counted once per group.

Forecast disclaimer: Forecasts are knowledge-based associations from documented ATT&CK relationships — not ML predictions, not probability scores, and not guarantees of future attacker behaviour.

Language disclaimer: Reports use cautious language ("indicates suspicious activity", "consistent with a possible multi-stage attack", "requires investigation"). No usernames, machines, credentials, or business impact are invented beyond what is present in the source dataset.
