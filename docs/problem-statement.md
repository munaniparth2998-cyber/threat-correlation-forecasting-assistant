# Problem Statement

Security Operations Centre teams receive thousands of alerts from firewalls, monitoring tools, and intrusion detection systems.

Manually reviewing each alert takes time and can delay the identification of serious attacks.

The proposed Threat Correlation & Forecasting Assistant groups related alerts, removes duplicate records, handles missing data, maps alerts to MITRE ATT&CK techniques, calculates threat scores, and forecasts possible threats.

The goal is to help SOC analysts identify important attack patterns quickly.
