# Methodology

1. Upload the CSV alert dataset.
2. Validate the alert records.
3. Remove duplicate alerts.
4. Handle missing timestamps.
5. Group alerts from the same source IP within a time window.
6. Map alert types to MITRE ATT&CK techniques.
7. Calculate threat scores.
8. Classify threat levels as Low, Medium, or High.
9. Generate a final security report.
10. Display the results on the dashboard.
